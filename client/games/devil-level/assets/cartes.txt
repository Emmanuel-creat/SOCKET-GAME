; ============================================================================
;  Devil Level — catalogue des cartes
;  Ce fichier est une RESSOURCE : le moteur y pioche par NOM. Pour ajouter un
;  niveau, il suffit de l'écrire ici — aucun code à toucher, aucun rebuild.
; ============================================================================
;
;  FORMAT
;    [Nom de la carte]       ← démarre une nouvelle carte (le nom sert de clé)
;    @theme prairie          ← facultatif : prairie, crepuscule, glacier,
;                              volcan, nuit, bonbon
;    @auteur Nathan          ← facultatif, purement informatif
;    (puis la matrice, ligne par ligne, jusqu'à la carte suivante)
;
;  Une ligne commençant par « ; » est un commentaire et n'est jamais lue.
;  Attention : « # » et « = » sont des BLOCS — ils ne peuvent servir ni de
;  commentaire ni de marqueur, sinon une rangée de terrain passerait pour un titre.
;
;  CONVENTIONS
;    - la PREMIÈRE ligne de la matrice est le HAUT du niveau ;
;    - les lignes peuvent être de longueurs différentes ;
;    - l'espace et le point valent « vide » (le point aide à compter) ;
;    - « P » (départ) et « D » (sortie) sont OBLIGATOIRES ;
;    - les lignes vides à l'intérieur d'une matrice sont des rangées d'air et
;      comptent ; celles du début et de la fin sont ignorées.
;
;  LÉGENDE
;    TERRAIN   # bloc     = plateforme   Z fuyante    r faux sol
;              b cassable i invisible    c glace      s collant
;              o mou      w temporisé    B trampoline l échelle
;              M plateforme mobile (horizontale)  V (verticale)
;    DANGERS   ^ pics     * scie         ! laser      T écraseur
;              ~ lave     x bloc explosif
;    SABOTAGE  O plaque   | bloc armé (tombe sur ceux qui suivent)
;    PARCOURS  P départ   K checkpoint   D sortie     t téléporteur (par paires)
;              g inversion de gravité
;    BONUS     C aléatoire
;              1 dash  2 double saut  3 bouclier  4 ghost
;              5 vitesse  6 gel  7 tornade  8 bombe
;              (alias hérités : W = double saut, S = ghost, H = bouclier,
;               Q = bombe)
;
; ============================================================================
